# مخططات حالات الاستخدام - نظام BloodConnectHub

هذا المجلد يحتوي على مخططات حالات الاستخدام (Use Case Diagrams) لنظام BloodConnectHub مكتوبة بصيغة **Mermaid** وباللغة **العربية**.

## 📁 الملفات المتوفرة

### 1. **system-overview.md**
مخطط شامل يعرض جميع حالات الاستخدام في النظام مع جميع الأدوار (زائر، متبرع، موظف، مدير، نظام).

**يتضمن:**
- 🌐 الوصول العام
- 🩸 وظائف المتبرع
- 👨‍⚕️ وظائف الموظف
- 👨‍💼 وظائف المدير
- 🤖 وظائف النظام التلقائية

### 2. **donor-use-cases.md**
مخطط مفصل لجميع حالات الاستخدام الخاصة بالمتبرع.

**يتضمن:**
- 🔐 المصادقة وإدارة الملف الشخصي
- 📊 لوحة التحكم والإحصائيات
- 🩸 إدارة طلبات الدم
- 📝 إدارة الاستجابات
- 💉 تتبع التبرعات
- 🔔 إدارة الإشعارات
- ℹ️ المعلومات والدعم

### 3. **admin-use-cases.md**
مخطط مفصل لجميع حالات الاستخدام الخاصة بالمدير.

**يتضمن:**
- 📊 لوحة تحكم المدير
- 👥 إدارة المستخدمين والأدوار
- 👨‍⚕️ إدارة الموظفين
- 🩸 إدارة المتبرعين (مستوى المدير)
- 🏥 إدارة المرضى (مستوى المدير)
- 💉 إدارة التبرعات (مستوى المدير)
- 📦 إدارة المخزون (مستوى المدير)
- 📋 إدارة طلبات الدم (مستوى المدير)
- 📈 التقارير والتحليلات الشاملة
- ⚙️ إعدادات النظام
- 🔔 إدارة الإشعارات
- 🔒 التدقيق والأمان

## 🔧 كيفية عرض المخططات

### الطريقة 1: عرض مباشر في GitHub
- افتح أي ملف `.md` في GitHub
- سيتم عرض مخططات Mermaid تلقائياً

### الطريقة 2: استخدام VS Code
1. قم بتثبيت إضافة **Markdown Preview Mermaid Support**
2. افتح أي ملف `.md`
3. اضغط `Ctrl+Shift+V` لعرض المعاينة

### الطريقة 3: استخدام Mermaid Live Editor
1. افتح [Mermaid Live Editor](https://mermaid.live/)
2. انسخ كود Mermaid من أي ملف
3. الصق الكود في المحرر
4. سيتم عرض المخطط تلقائياً

### الطريقة 4: تصدير كصورة
استخدم Mermaid CLI لتصدير المخططات كصور:

```bash
# تثبيت Mermaid CLI
npm install -g @mermaid-js/mermaid-cli

# تصدير كصورة PNG
mmdc -i system-overview.md -o system-overview.png

# تصدير كصورة SVG
mmdc -i donor-use-cases.md -o donor-use-cases.svg
```

## 📊 نظرة عامة على الأدوار

### 🎭 الأدوار في النظام

| الدور | الوصف | الصلاحيات الرئيسية |
|------|-------|-------------------|
| **👤 زائر** | زائر غير مسجل | عرض المعلومات العامة، التسجيل، تسجيل الدخول |
| **🩸 متبرع** | متبرع مسجل | الاستجابة للطلبات، عرض التبرعات، إدارة الملف الشخصي |
| **👨‍⚕️ موظف** | موظف بنك الدم | إدارة المتبرعين، التبرعات، المخزون، الطلبات، التقارير |
| **👨‍💼 مدير** | مدير النظام | جميع صلاحيات الموظف + إدارة المستخدمين، الأدوار، إعدادات النظام |
| **🤖 نظام** | النظام التلقائي | إرسال الإشعارات، إزالة الوحدات المنتهية، التنبيهات |

## 🔗 العلاقات بين حالات الاستخدام

### Include (يتضمن)
تستخدم عندما تكون حالة استخدام جزءاً إلزامياً من حالة أخرى:
- "تسجيل تبرع" يتضمن "فحص أهلية المتبرع"
- "تنفيذ طلب" يتضمن "تحديث المخزون"
- "الموافقة على متبرع" يتضمن "التحقق من الوثائق الطبية"

### Extend (يمتد)
تستخدم عندما تكون حالة استخدام اختيارية:
- "طباعة تقرير" يمتد من "عرض التقارير"
- "إرسال إشعار" يمتد من معظم العمليات
- "تصدير بيانات" يمتد من عرض القوائم

## 📝 ملاحظات مهمة

1. **التسلسل الهرمي للأدوار:**
   - Donor يرث من Guest
   - Staff يرث من Guest
   - Admin يرث من Staff (له جميع صلاحيات Staff + صلاحيات إضافية)

2. **فصائل الدم المدعومة:**
   - A+, A-, B+, B-, AB+, AB-, O+, O-

3. **حالات طلب الدم:**
   - Pending (معلق)
   - Fulfilled (منفذ)
   - PartiallyFulfilled (منفذ جزئياً)
   - Cancelled (ملغى)

4. **مستويات الاستعجال:**
   - Normal (عادي)
   - Urgent (عاجل)
   - Emergency (طارئ)

5. **حالات التبرع:**
   - Pending (معلق)
   - Approved (مقبول)
   - Rejected (مرفوض)

## 📞 للمزيد من المعلومات

للحصول على معلومات تفصيلية عن أي حالة استخدام، يرجى الرجوع إلى:
- وثائق API في `/src/api/`
- ملفات الأنواع في `/src/types/`
- مكونات الواجهة في `/src/components/`
- صفحات التطبيق في `/src/pages/`
