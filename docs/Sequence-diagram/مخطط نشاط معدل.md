sequenceDiagram
    participant M as المتبرع
    participant N as النظام
    participant A as المسؤول


    Note over M,A: تسجيل ومصادقة المستخدمين
    M->>N: تسجيل حساب جديد (Register)
    N->>M: تأكيد التسجيل
    M->>N: تسجيل دخول (Login)
    N->>M: رمز المصادقة (Token)

    Note over M: إنشاء ملف المتبرع
    M->>N: إنشاء ملف متبرع مع الوثائق الطبية
    N->>A: إشعار بمتبرع جديد يحتاج موافقة
    A->>N: مراجعة الوثائق الطبية
    A->>N: الموافقة على المتبرع أو رفضه
    N->>M: إشعار بنتيجة الموافقة

    Note over M,A: طلب دم جديد
    N->>M: طلب دم عاجل (Blood Request)
    N->>A: إشعار بطلب جديد
    A->>N: مراجعة الطلب
    N->>M: إشعار للمتبرعين المؤهلين

    Note over M,A: استجابة المتبرع
    M->>N: الاستجابة للطلب (مهتم بالتبرع)
    N->>A: إشعار باستجابة متبرع
    A->>N: تأكيد الموعد مع المتبرع
    N->>M: إشعار بتأكيد الموعد

    Note over M,A: عملية التبرع
    M->>A: الحضور للتبرع
    A->>N: تسجيل التبرع
    N->>N: تحديث حالة المتبرع (غير مؤهل مؤقتاً)
    A->>N: إجراء الفحوصات المخبرية
    N->>A: نتائج الفحوصات
    
    alt نتيجة الفحص إيجابية
        A->>N: تحديث حالة التبرع (مقبول)
        N->>N: إضافة للمخزون
        A->>N: تنفيذ طلب الدم
        N->>M: إشعار بنجاح التبرع
    else نتيجة الفحص سلبية
        A->>N: تحديث حالة التبرع (مرفوض)
        N->>M: إشعار بعدم قبول التبرع
    end
