# مخططات النشاط - نظام BloodConnectHub

هذا المجلد يحتوي على مخططات النشاط (Activity Diagrams) لنظام BloodConnectHub مكتوبة بصيغة **Mermaid** وباللغة **العربية**.

## 📁 الملفات المتوفرة

### 1. **system-overview-activity.md**
مخططات النشاط العامة للنظام تغطي العمليات الأساسية المشتركة.

**يتضمن:**
- 🔐 تسجيل الدخول والمصادقة
- 📋 إنشاء طلب دم جديد
- 💉 تسجيل تبرع جديد
- 🧪 إجراء فحص مخبري وتحديث المخزون
- ✅ تنفيذ طلب دم
- 🤖 إزالة الوحدات المنتهية تلقائياً (عملية النظام)

### 2. **donor-activity.md**
مخططات النشاط الخاصة بالمتبرع تغطي جميع عمليات المتبرع.

**يتضمن:**
- 📝 تسجيل متبرع جديد
- 🩸 الاستجابة لطلب دم
- 📊 عرض وتتبع التبرعات
- 📋 إدارة الاستجابات
- 🔔 إدارة الإشعارات

### 3. **admin-activity.md**
مخططات النشاط الخاصة بالمدير تغطي جميع عمليات الإدارة.

**يتضمن:**
- ✅ الموافقة على تسجيل متبرع
- 👥 إدارة المستخدمين والأدوار
- 📊 إنشاء وجدولة التقارير
- 📦 إدارة المخزون وتنبيهات المخزون المنخفض
- 🔒 مراجعة سجلات التدقيق والأمان

## 🔧 كيفية عرض المخططات

### الطريقة 1: عرض مباشر في GitHub
- افتح أي ملف `.md` في GitHub
- سيتم عرض مخططات Mermaid تلقائياً

### الطريقة 2: استخدام VS Code
1. قم بتثبيت إضافة **Markdown Preview Mermaid Support**
2. افتح أي ملف `.md`
3. اضغط `Ctrl+Shift+V` لعرض المعاينة

### الطريقة 3: استخدام Mermaid Live Editor
1. افتح [Mermaid Live Editor](https://mermaid.live/)
2. انسخ كود Mermaid من أي ملف
3. الصق الكود في المحرر
4. سيتم عرض المخطط تلقائياً

### الطريقة 4: تصدير كصورة
استخدم Mermaid CLI لتصدير المخططات كصور:

```bash
# تثبيت Mermaid CLI
npm install -g @mermaid-js/mermaid-cli

# تصدير كصورة PNG
mmdc -i system-overview-activity.md -o system-overview-activity.png

# تصدير كصورة SVG
mmdc -i donor-activity.md -o donor-activity.svg
```

## 📊 نظرة عامة على مخططات النشاط

### 🎯 ما هي مخططات النشاط؟
مخططات النشاط (Activity Diagrams) هي نوع من مخططات UML تُستخدم لتوضيح سير العمل (Workflow) والعمليات في النظام. تُظهر تسلسل الأنشطة والقرارات والتفرعات.

### 🔑 العناصر الأساسية

| العنصر | الوصف | الرمز في Mermaid |
|--------|-------|------------------|
| **نقطة البداية** | بداية العملية | `Start([بداية])` |
| **نقطة النهاية** | نهاية العملية | `End([نهاية])` |
| **نشاط** | خطوة في العملية | `[اسم النشاط]` |
| **قرار** | نقطة تفرع | `{سؤال؟}` |
| **قاعدة بيانات** | عملية تخزين | `[(حفظ)]` |
| **سهم** | اتجاه التدفق | `-->` |

## 🎨 دليل الألوان المستخدم

| اللون | الاستخدام | الكود |
|------|----------|-------|

## 📋 قائمة المخططات حسب الدور

### 👤 الزائر (Guest)
- تسجيل الدخول والمصادقة

### 🩸 المتبرع (Donor)
- تسجيل متبرع جديد
- الاستجابة لطلب دم
- عرض وتتبع التبرعات
- إدارة الاستجابات
- إدارة الإشعارات

### 👨‍⚕️ الموظف (Staff)
- إنشاء طلب دم جديد
- تسجيل تبرع جديد
- إجراء فحص مخبري
- تنفيذ طلب دم

### 👨‍💼 المدير (Admin)
- جميع عمليات الموظف +
- الموافقة على تسجيل متبرع
- إدارة المستخدمين والأدوار
- إنشاء وجدولة التقارير
- إدارة المخزون المتقدمة
- مراجعة سجلات التدقيق والأمان

### 🤖 النظام (System)
- إزالة الوحدات المنتهية تلقائياً
- فحص المخزون المنخفض
- إرسال الإشعارات التلقائية

## 🔄 العمليات الرئيسية

### 1. دورة حياة المتبرع
```
التسجيل → الموافقة → الاستجابة للطلبات → التبرع → الفحص → إضافة للمخزون
```

### 2. دورة حياة طلب الدم
```
إنشاء الطلب → إشعار المتبرعين → استجابة المتبرعين → تأكيد التبرع → تنفيذ الطلب
```

### 3. دورة حياة التبرع
```
تسجيل التبرع → الفحص المخبري → الموافقة/الرفض → إضافة للمخزون → الاستخدام/الانتهاء
```

### 4. دورة حياة وحدة الدم
```
إنشاء → متاحة → محجوزة → مستخدمة
                  ↓
              منتهية (بعد 42 يوم)
```

## 🔔 الإشعارات التلقائية

### أنواع الإشعارات
1. **للمتبرعين:**
   - طلب دم جديد يطابق فصيلة الدم
   - تحديث حالة الاستجابة
   - موافقة/رفض التسجيل
   - نتائج الفحوصات المخبرية
   - تذكير بموعد التبرع

2. **للموظفين:**
   - استجابة متبرع جديدة
   - طلب دم عاجل
   - مخزون منخفض
   - وحدات قريبة من الانتهاء

3. **للمدراء:**
   - طلب تسجيل متبرع جديد
   - مخزون حرج
   - تنبيهات أمنية
   - تقارير مجدولة

## 📈 مقاييس الأداء

### أوقات الاستجابة المتوقعة
- تسجيل الدخول: < 2 ثانية
- تحميل البيانات: < 3 ثواني
- حفظ البيانات: < 2 ثانية
- إنشاء التقارير: < 10 ثواني
- تصدير البيانات: < 15 ثانية

### معدلات النجاح المستهدفة
- تسجيل الدخول: > 99%
- حفظ البيانات: > 99.9%
- إرسال الإشعارات: > 98%
- إنشاء التقارير: > 95%
